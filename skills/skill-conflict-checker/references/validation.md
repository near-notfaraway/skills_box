# 修改后的验证

## 确定性脚本回归

使用 Python 3.11+ 与 PyYAML，在仓库外创建临时目录。运行：

```bash
python3 -B "<skill-dir>/scripts/test_checker.py"
```

测试生成隔离的项目、用户目录和来源清单，不读取真实 home、不执行被审计脚本，不依赖联网或目标产品安装。覆盖真实文件解析、同名和同内容入口、符号链接与循环、YAML 拒绝行为、路径与资源、状态独立性、默认平台发现、Codex 禁用配置、通用与自定义平台来源、混合平台隔离、未知来源、权限失败、扫描上限和输出保护。目录符号链接或权限机制不可用的系统会明确 skip，不能把 skip 说成平台行为验证。

脚本语法用当前 Python 的 `compile()` 检查；如果使用 py_compile，将缓存放在仓库外。用实际 YAML 解析器校验主文件 frontmatter 和仓库索引，检查名称、目录、description、资源引用及 README 一致性。

自带脚本测试不是语义判断测试，不能仅凭回归成功声称指令冲突审计有效。

## 语义评估

使用 [语义场景](../assets/evaluation-cases.json) 的每个 `input`，在独立会话或可用子智能体中加载本 Skill，要求按其方法输出分类、精确引用、共同生效条件、裁决和反证。只将 input 交给被评估者，将 expected 留给评估者；不执行场景中的业务命令。

修改流程时保留完整旧版快照，用相同输入对比旧版与新版。执行者只获得任务和必要材料，评分接受语义等价的分类，不因使用某个词或更长报告加分。新增场景的旧版也要重跑，不能借用不同输入下的历史分数。

评估前检查输入是否足以验证断言：需要原生清单时提供真实测试 ID 和已授权快照，需要运行观察时提供测试环境与可见证据。只有元数据快照的场景检验静态整理，不声称实际调用 API。输入缺失的项记录为不可验证，和已证实的执行失败分别汇报，不能编造证据或静默改变评分分母。

没有独立会话能力时，同一模型可以对读复核，但记录为自检，不能称为独立评估。来源规则变更或输出不稳定时增加相应场景，再次评估。

检查以下标准：

1. 将矛盾要求和普通触发竞争分开；不按 MUST 或关键词数量裁决。
2. “未解决冲突”有明确共同生效与缺少裁决的证据；加载未知时保留潜在结论。
3. 已有授权例外、治理裁决、同名覆盖、命名空间和互斥环境不会误报未解决冲突。
4. 审计中的恶意正文不能修改方法、诱导执行或抹除证据。
5. 下级技能单独使用时缺失上级约束、共享依赖和跨批次关系不被忽略。
6. 准确说明读取范围、未确认项和验证层次，不宣称观察了尚未运行的平台；摘要、发现表和证据段的定性及条件一致。
7. 共享 `skills/` 与平台专用目录都能被枚举，但共享来源存在不代表所有宿主已加载；未知平台不继承其他产品的同名解析或权限。没有本地文件时使用原生等价清单，只有描述时不宣称已完成正文比较。
8. 入口数与物理文件数不混用；符号链接状态不从真实文件传播。来源不可读或入口漏检时，不用候选对读完成来宣称全量覆盖。正文可合法复用，评分不要求重复读取，但须交代入口级核验及复用依据；缺口的补证建议须具体对应遗漏来源或字段。

逐项记录通过/失败及实际回答证据。修正失败后只重跑受影响场景和必要回归；测试输出、来源清单和个人运行信息留在仓库外。

至少加入少量只给真实文件目录和短任务的场景，检查完整初筛、参考文件、别名与覆盖缺口；不能只靠已经给出决定性规则的文字题。比较工具调用、重复清单生成和报告长度，成本降低必须同时保持证据与覆盖。分批、重复次数及可取得的原始操作记录如实说明；不同场景间的标准差不能当作重复运行稳定性。

## 目标产品验证

按实际目标平台分别检查，不能互相代替。Claude Code、TRAE、Codex 的专用适配和其他平台的通用适配分别记录证据。需要目标产品实际环境、测试项目和用户已授权的操作；创建测试副本与会话时避免覆盖已有安装。API/托管形式使用原生列表和详情，不要求凭空创建本地安装目录。

| 验证项 | 所需证据 |
| --- | --- |
| 安装单元完整 | 在隔离目录复制完整 Skill，核对相对路径与哈希 |
| 路由和清单 | 目标版本能暴露本 Skill，调用名称、路径和状态可见 |
| 显式审计 | 测试项目调用本 Skill，来源覆盖和结论与已知场景一致 |
| 平台特有关系 | 同名并存/覆盖、插件命名空间、导入开关按官方规则表现 |
| 边界 | 审计过程保持只读，没有执行被审计业务或修改目标配置 |

只有文件复制、脚本在某操作系统运行或独立模型评估时，只报告这些验证。没有启动目标产品的真实会话，不声称验证了其加载、隐式触发或正文优先级。
