# 可复用验收场景

以下是维护者可重复执行的检查要求，不是对某次执行的结果记录。测试输入与临时输出放仓库外，测试计数不写入技能源配置或来源索引。

## 静态检查

- 用 YAML 解析器读取主 SKILL.md，检查名称与目录一致、description 明确用途和触发、正文非空。
- 解析全部 JSON 资源；检查来源 ID 唯一、配置字段有效、API 映射与当前实际返回对应。
- 检查主文件引用存在、路径可迁移，没有作者机器路径或未说明的运行依赖。
- 在不生成仓库内缓存的情况下完成 Python 编译检查，执行脚本代表性命令。
- 校验原创索引 YAML、README 链接与实际目录一致。

## 行为验收

| 场景 | 期望行为 |
| --- | --- |
| 添加网站/JSON API | 保存本地新源，默认源保持可用 |
| 禁用内置源 | 只写本地覆盖；重新启用恢复查询 |
| 来源 ID 冲突 | 未请求替换时拒绝覆盖 |
| 凭据缺失、请求拒绝或超时 | 明确来源状态，其他来源结果保留 |
| 返回格式变化 | 返回格式错误，不报告零结果 |
| 多关键词检索 | 相同目录条目仍是一个候选 |
| 品牌名、安装名、仓库名不同 | 精确反查各名称并用上游证据归并，不因单个近似名称核验失败而排除其他候选 |
| 同源被多站收录 | 查明实际路径后合并，保留各站独立指标 |
| 待核验升级、互补证据、重复合并 | 两种输入顺序均保留有效推荐，原始观察保留且不重复 |
| 相反事实、显式冲突、不同评估 | 所有输入顺序均暂停推荐，不被后续普通记录清除 |
| 同名不同发布者或 fork | 保持独立候选 |
| 路径未知/不同分支 | 不猜路径或提前合并 |
| 热度或维护数据缺失 | 保留未知、区间与证据缺口 |
| 平台/许可不满足 | 推荐前排除，不靠热度补偿 |
| 未读上游或评估无证据 | 不进入正式推荐或拒绝无证据打分 |
| 不同功能组 | 分组比较，不判跨组唯一赢家 |
| 关键来源失败或高影响名称有歧义 | 尝试替代检索；缺口未消除时只给暂定首选 |
| 公共 API 缓存 | 重用结果并保留观测时间；刷新绕过缓存 |
| 必需资源缺失 | 静态校验报告具体缺口 |

网络适配测试可使用任务临时目录中的本地 HTTP 服务，验证真实请求、字段映射、缓存和失败隔离。测试数据明确属于测试夹具，不进入用户推荐或真实指标报告。

可移植的回归脚本位于 `scripts/test_finder.py`，使用标准库 unittest、本地 HTTP 服务与任务临时目录；完整测试还需 PyYAML。脚本不会访问外部网站、修改默认源或安装真实 Skill：

```bash
python3 "{baseDir}/scripts/test_finder.py" -q
```

## 代表性只读场景

- “找操作个人微信的 Skill”：区分个人微信、公众号发布、小程序开发与 Agent 微信接入；检查平台、配套软件、激活及许可证条件。
- “找处理 PDF 的 Skill”：比较具体任务覆盖、脚本资源、文档与运行依赖，不能仅凭仓库星数推荐。
- “首轮只有局部功能的 PDF 备选”：做一次针对性扩展，完整流程候选优先，局部工具不占完整备选名额；达到预算即交付实际数量。
- “找让前端更有设计感的 Skill”：广检后对高信号名称做精确反查；遇到 `Taste Skill`、`design-taste-frontend`、`taste-skill` 这类品牌名、安装名与仓库名不一致的情况，核对上游对应关系后再排名。某个同类名称无法核验，不能扩大为整个名称族都不可用。
- “有许可摘要但原文读取失败”：精确许可/激活结论保持未知，必要条件不明的候选不进正式推荐；证据文件可直接复核。
- “页面读取器只返回标题但 HTML 已有条目”：按已取得的候选更新来源说明，不报零结果；保留不同请求的原始响应，避免大小写文件名覆盖。
- “加入一个自定义社区”：先用网站源完成站点检索；有正式 JSON API 后验证实际字段，再增加完整映射。
- “仅用本地技能库查找”：处理缺少 PyYAML、坏 frontmatter、无匹配与目录不存在等不同状态。

真实网络验证分别记录脚本 API、官方 CLI 和 Agent 网站检索的实际覆盖。CLI 缺失或需认证时报告尚未验证，不通过执行业务流程补证。
