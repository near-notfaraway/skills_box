# 配置交付模板

用户需要字段清单，或复杂配置需要逐项交接时使用。简短任务直接报告相关字段，无需填写整表。先在回答中输出完整 prompt，再补充必要字段；清单不能替代完整 prompt。删除不适用的行，替换全部占位项并明确实际完成状态。不要把配置建议写成已保存结果。

| 项目 | 具体值 |
| --- | --- |
| 工作模式 | 【prompt / configure / full】 |
| 目标平台与版本 | 【平台；已核对版本或版本未确认】 |
| Agent 名称 / 标识 | 【显示名称；唯一标识】 |
| 作用范围 / 目标位置 | 【用户级、项目级或选定工作空间】 |
| 调用描述 / 展示简介 | 【平台支持的具体字段和值】 |
| Prompt | 【完整正文或可访问文件链接】 |
| 模型 | 【继承、平台默认或已验证的具体模型】 |
| 工具、知识和资源 | 【已经接入；仍待配置】 |
| 权限 | 【实际配置及其边界；未核实就标明】 |
| 当前状态 | 【Prompt 已生成，需用户自行配置 / 配置已保存 / 平台已发现 / 行为已验证】 |

必要的后续操作：给出与当前平台一致的精确步骤、保存位置和发现方式。没有执行的试运行单独列为建议，不能标为已验证。
