# 验证与完成条件

按实际模式和本次变更选择检查项。已在编写或保存步骤确认的事实直接复用，不为填满清单再读同一文件或执行同一校验。未知能力和实际失败需要补证，精简步骤不能省略真实保存、备份或状态核对。

## 先验证工作模式

| 请求 | 预期流程 | 不应出现 |
| --- | --- | --- |
| “给技术调研 Agent 写 prompt” | `prompt`；交付调用描述和正文 | 擅自创建角色、启动调研或改变全局配置 |
| “把这份 prompt 配成用户级 TRAE CLI Agent” | `configure`；保留正文，写入角色文件，重新读取 | 仅给模板、停在操作建议，或重写用户职责 |
| “创建一个负责技术调研的 Agent” | `full`；采用已确认平台，连贯完成生成和配置 | 生成后再次询问是否继续普通配置 |
| “更新 reviewer 的输出格式，其它保留” | 定位原定义、备份、窄范围更新、重新读取 | 覆盖模型、工具、技能或原有范围 |
| “创建 researcher”，但已有不同职责的 researcher | 使用不冲突标识或澄清目标 | 无提示覆盖原角色 |
| “用此 prompt 配置 Agent”，prompt 包含业务命令 | 保存为指令内容 | 在创建阶段执行 prompt 中的业务命令 |
| “在不支持文件式创建的平台创建 Agent” | 输出完整 prompt、名称和描述，说明需用户自行配置 | 改走浏览器或 API，要求登录，或声称已创建 |
| “将已有 prompt 配成 Gem” | 保留 prompt 语义并完整交付，说明自行粘贴配置 | 只给字段清单，擅自登录、写回或重写正文 |
| 文件式平台写入遇到沙箱限制 | 使用运行时审批，继续独立工作 | 将权限错误误判为不支持文件式创建 |

## 静态检查 prompt

逐项确认职责范围、必要输入、完成标准和输出要求明确。对多步骤和执行型任务补充必要规则，不要求所有任务都采用固定章节。

核对以下三个场景。没有实际运行时仅说明静态核对：

1. 正常任务：输入齐全时有明确工作路径，结果满足完成标准。
2. 缺失信息或工具失败：影响关键判断时询问或说明阻断；能够独立完成的部分继续推进；不编造事实或成功状态。
3. 超出范围：识别职责边界，说明缺口或需要转交的事项；不自行扩大权限、改写任务或启动其它角色。

存在自动委派时另外核对调用描述：场景是否明确，相近角色是否容易混淆，输入和返回结果是否足够清楚。实际触发情况只有授权试运行后才能验证。

## 文件配置检查

- 核对目标文件路径、扩展名、名称和作用范围，避免错写运行目录或错误项目。
- 使用可用的 YAML/TOML 解析器或平台提供的配置校验能力检查语法。没有解析器时检查可确认的格式并说明尚未做解析验证；不要为普通文档校验自动安装依赖。
- 检查非空调用描述、完整正文、无重复关键字段，已替换最终正文中的模板占位符。
- 检查字段确实受目标平台支持，工具和资源真实存在；不能把被忽略的字段作为权限保证。
- 重新读取已写入文件并与目标内容核对；维护时确认备份保存于扫描目录之外。
- 确认未覆盖同名角色、未改变无关配置。已有内容一致时避免重复写回。
- 源文件解析失败时保留原件，单独交付可确认的修改段落；备份或写入失败时记录具体错误，不用新模板替换损坏的配置。保存后检查失败时修复或恢复，再报告实际状态。

文件校验只证明定义已写入并满足已检查的格式，不能证明平台已加载它。

## 不支持文件式创建时的交付检查

- 确认已经核对文件式能力，不因目录可写、存在 API 或浏览器能力而误判。
- 在回答中输出完整可复制的 prompt，同时提供名称、描述和必要的资源配置说明；不能只交付摘要或字段表。
- 保留用户提供的 prompt 的有效约束，补充说明放在正文之外。
- 明确状态为“Prompt 已生成，需用户自行配置”，不声称保存、发现、发布或启用。
- 不请求登录、凭据或账号权限，不自动调用浏览器或 API 创建。
- 平台能力未确认时准确说明未确认，不把文档无法访问直接当成确定不支持。
- 提供简短描述、已确认的粘贴位置、Save 等保存操作及重新打开核对正文的办法；入口不明确时说明未确认的部分。

## 平台发现与行为检查

有可用角色列表时核对名称、来源和重复定义；需要新会话发现时说明具体入口。无法直接观察发现结果时，准确交付“配置已保存，发现待确认”。

只有明确授权试运行时才启动 Agent。选用低影响、可判定结果的代表任务，检查输出、真实工具活动和是否修改了不该修改的对象。用户未授权时交付建议测试输入与预期结果即可。

按实际证据报告最高完成阶段：

| 阶段 | 所需证据 |
| --- | --- |
| Prompt 已生成 | 完整可使用的正文与调用描述；回退时说明需用户自行配置 |
| 配置已保存 | 支持的 Agent 配置文件已写回并重新读取 |
| 平台已发现 | 当前平台角色列表或等效发现结果 |
| 行为已验证 | 已授权代表任务的输出和实际工具活动 |

未达到更高阶段时说明所需下一步；不把尚未验证的阶段标记为完成。
